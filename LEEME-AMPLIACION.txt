INSTALACIÓN
1. Haz copia de seguridad del repositorio actual.
2. Descomprime este paquete en la carpeta raíz de tu repositorio Radar-depositos, manteniendo la estructura de carpetas. Sustituye el archivo data/offers.json después de comprobar que no hay actualizaciones más recientes que debas conservar.
3. Haz commit y push a la rama main. El archivo index.html existente carga los datos desde data/offers.json.
4. En GitHub, Settings > Pages, selecciona 'GitHub Actions' como fuente (si aún no está seleccionado).
5. En GitHub, Actions, elige 'Revisar depósitos y publicar web (cada hora)' y Run workflow.
6. Comprueba el log de la ejecución y la web publicada. Las revisiones programadas de GitHub Actions pueden retrasarse o no ejecutarse en un ciclo determinado.

ATENCIÓN
• Ninguna tasa tiene actualización automática garantizada: depende de la disponibilidad y estructura de cada página del banco.
• El monitor no altera una TAE si no consigue extraerla, y no publica oscilaciones de más de 1 punto porcentual sin revisión.
• Si cambia una TAE y no se logra identificar el nuevo TIN, la TIN queda sin publicar para evitar mostrar datos antiguos.
• Compara las condiciones completas, especialmente fondos de garantía, promociones, vinculación, fecha de vigencia y cancelación.
• 32 ofertas NO equivalen a la totalidad del mercado. Pibank, Facto, Banco BiG, Banca March, Santander, Bankinter, BBVA, Sabadell, CaixaBank, ING y otras entidades quedan en lista de ampliación pendiente de revisión.
• No confundas el depósito a plazo con cuentas remuneradas o depósitos combinados con fondos de inversión.
